# ETKN TV 0.1.130：歌曲标签、目录卡片与歌词

日期：2026-11-17。

## 变更

- 音乐库在歌手与文件夹之间增加“歌曲”标签，复用 `/api/tv/Users/{user_id}/Music?Tab=songs`，保留当前媒体库范围，按最新入库降序滚动分页。点击歌曲沿用当前列表的播放队列与后续分页。
- 音乐文件夹的目录封面使用独立的 140dp 目标网格，歌曲使用 300dp 目标的紧凑横向网格；第二层及以后不再将目录封面放入歌曲宽网格。
- 音乐播放页初始直接打开歌词，可切换歌曲列表；保持同名 LRC、内嵌歌词、空文本时在线下载的现有顺序。
- 解析时过滤普通空白行及只含时间戳的 LRC 空行，保留有效歌词原时间戳、偏移、多时间戳和译文合并。
- 仅修改 TV；本轮无 ETKvNext 服务端、Web 或生产容器变更。
