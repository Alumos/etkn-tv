# 播放分集列表密度修复

2026-11-16；应用0.1.122 / versionCode123；仅本地提交与ADB覆盖安装。

## 目标和结论

用户反馈播放页分集卡片即使设为“小”也只能显示不到2集，明确要求“极大”挡位也要完整显示至少3集。原卡片采用固定360dp面板内的整宽剧照与竖向文字，没有读取五档卡片设置。

改成左侧16:9剧照、右侧集号/标题/最多三行简介的紧凑行列表。面板宽度、剧照、文字、行高和间距使用现有五档设置；行高按实际列表视口封顶为三等份并扣除留白和间距，文字随可用高度同步缩放。电视与模拟器均为1920×1080、density320，即960×540dp；在该尺寸下极大完整显示3集，小完整显示4集。

## 实际修改

- PlayerEpisodePanel：横向图文行，保留正在播放、已观看、主题色进度、焦点边框和占位集播出日期；去掉正文与日期默认的多余上下内边距，长简介保留三行。五档变更直接更新现有控件，保留加载数据、当前播放与遥控器焦点。
- PlayerActivity：面板宽度使用同一尺寸入口。打开或恢复分页焦点时将目标集定位在可见列表顶部，季海报仍可向上进入。
- 保持EpisodePage每页40集、可见剧照才请求、慢前页等待保焦点、NextEpisode独立查询及详情选集禁止上键唤出主菜单的既有修复。
- 新增一个仪器场景，在420集合成数据和长三行简介下遍历五档，断言完整分集数量不少于3、尺寸递增、图文可见且换挡不重建列表/丢焦点；补充多季、播出日期加三行简介的极大挡位检查。
- AGENTS.md记录极大至少完整3集的长期约束；版本递增为0.1.122/123。没有修改服务端与播放器解码/传输链路。
