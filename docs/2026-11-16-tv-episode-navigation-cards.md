# TV 分集向上导航与播放页分页卡片（0.1.121）

## 目标与结论

修复详情选集矩阵连续向上时主菜单抢走焦点、难以返回已观看集的问题；按用户明确要求取消选集页的上键唤出主菜单。播放中的右侧选集改为参考 Web 的剧照、标题与简介卡片，按需分页，并 ADB 保留数据覆盖更新 192.168.31.188。

用户样本为《炼气十万年》420集，允许分页等待，核心要求是等待和向上导航时焦点不能被菜单抢走。基线420集延迟前页测试复现：到顶部继续按上键时菜单显示，预期GONE，实际VISIBLE。

## 实际变更

- DetailActivity 显式按列数定位上一行；首行尚有前页时读取前页并接住上键；单季绝对顶部留在矩阵，多季仍可进入季选择。episodePicker 禁止上键唤出主菜单，普通详情的原入口保留。
- 保留0.1.120的独立透明矩阵裁剪框，向上和向下均不推动剧照、简介越界。
- PlayerEpisodePanel 使用 EpisodePage 每页40集，首次 AnchorId 精确定位当前集；前页不足40集使用实际剩余数量，防止从任意锚点返回前集后重叠。
- 播放页右侧宽度最多360dp，竖向卡片显示16:9剧照、集号、标题、最多3行简介、已观看/正在播放状态与进度；保留占位集播出日期。季海报随列表滚动，独立固定裁剪父层限制所有滚动内容。
- 只有可见剧照才开始图片请求；追加页不重建现有卡片，前插页恢复当前焦点。前页加载中重复上键不会外跳，关闭面板后迟到结果不得抢焦点。
- 下一集使用现有独立 NextEpisode 接口，保持跨季、跳过占位、目标季音轨序号、停止上报和自动续播；面板及下一集不再拉取整剧。其他队列解析未扩展重构。
- 应用0.1.121 / versionCode122。服务端实现未改；仅同步TV与ETKvNext的分集规则和短期上下文。

## 可复用规则

TV滚动区域使用独立且不随内部scrollY变化的显式裁剪父层。遥控器按数据索引导航，不能让被裁剪行的focusSearch空结果成为主菜单触发条件。EpisodePage锚点是精确偏移而非40集对齐，向前加载的Limit必须为min(40,start)。分页等待保留焦点，隐藏或过期响应不得夺回焦点。
