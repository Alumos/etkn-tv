# TV 媒体详情对齐 Web

2026-11-16；应用 0.1.123 / versionCode 124；指定电视 192.168.31.188:5555。

## 目标和实际修改

用户要求 TV 媒体详情与当前自有 Web 一致，保留 TV 剧集选集按钮、独立数字矩阵，并包含缺少中文字幕时显示实时翻译的逻辑。

- 背景改为右上等比原图，左侧与底部渐隐，低透明氛围层融入固定暗色背景；背景随详情滚动。
- 左侧信息区为可用宽度的 48%，标题与 Logo 共用固定 4:1 区域。Logo 等比缩放、左下对齐，直接遵守服务端 UseLogoAsTitle，不在客户端重复图片语言判断。加载期间及失败显示文字，开关改变而图片 URL 未改变也即时更新。
- 评分、年份/时长/分级/合集与公司、类型标签、操作按钮、轨道选项分行展示；新增当前版本的视频参数及导演入口。
- 简介最多六行，溢出显示可遥控聚焦的“更多”按钮及全文弹窗；演员自然排列，不强制首屏完整，不补留白。章节先于演员。
- 字幕自动项先显示服务端默认字幕；没有默认字幕且存在 SubtitleTranslation 时显示实时翻译/繁简转换与简中/繁中目标。手动字幕与关闭继续生效，实际播放复用原翻译链路。
- 保留 TV 独立选集按钮、数字矩阵分页、季海报与本季音轨序号锁定；未修改播放解码、传输与后端。
