# ETKN TV Revised 外观真机验收

此清单待执行。只安装 GitHub Actions 构建、使用 Revised 固定正式签名的 APK；不要在 Mac 上编译，也不要用 Debug 签名包替代。建议覆盖 720p 和 1080p 输出，包含一台较老的 Android TV，并同时试浅色和深色账号主题。

| 页面 | 操作 | 预期 |
| --- | --- | --- |
| 登录与选用户 | 在短、长服务器名和不同数量的已保存账号间切换；用方向键到用户名、密码、新用户和列表两端 | 登录控件等宽不溢出；账号卡片可横向浏览；确认键仍进入原流程。 |
| 背景 | 使用细节明显的壁纸，分别设置模糊为 0 和非 0，再测试玻璃透明度为零、中间值、全不透明；切账号并快速返回 | 模糊为 0 时保持清晰；有壁纸且开启模糊时，局部毛玻璃只出现在半透明登录/选用户面板内，不盖住内容。无图时退回主题底，旧账号壁纸不回填。 |
| 设置 | 逐项在普通菜单行和开关行间上下移动，切换主题，再按确认切换开关 | 标题左缘一致，箭头和开关垂直居中；摘要不压住开关；整行聚焦，每次确认只切换一次。 |
| 详情与选项 | 打开有和没有元数据的影片/剧集；打开版本、音轨、字幕选项，用长标签和多种已选项测试 | 没有空的元数据行；每行选中标记对齐，长文本最多两行；打开时可定位选中项，返回保持可操作焦点。 |
| 视频播放器 | 分别测试下一集存在/不存在、打开控制栏并横移到两端、按上键开分集面板，再测试左右快进退和返回 | 控件不因数量增加而被平均挤窄；超出可视区域时随焦点滚动；默认焦点、独立快进进度条和返回顺序不变；视频不被额外整屏压暗或模糊。 |
| 音乐 | 逐个聚焦播放按钮，切换歌词/队列和明暗主题；播放长歌名并翻阅队列 | 图标居中且可读；序号/播放标识和时长列不会随曲目切换左右跳动；菜单焦点不被裁切，返回仍停止播放。 |
| 首页 | 打开和关闭顶栏，再从设置/播放器返回；抽查五档卡片大小 | 顶栏依然不透明，首页原有壁纸、卡片缩放、阴影和焦点规则未改变。 |

若出现差异，记录机型、Android 版本、输出分辨率、主题/透明度和按键顺序。云端构建与静态检查均不能替代上述验收。
